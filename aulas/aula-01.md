# Aula 01 — Introdução à Programação

## Objetivo

Apresentar o conceito de programação e estimular o raciocínio lógico por meio de atividades simples e acessíveis.

## Conteúdos abordados

- O que é programação
- Algoritmos
- Sequência de comandos
- Lógica de execução
- Pensamento computacional

## Atividades propostas

- Exploração do conceito de instruções
- Criação de sequências simples
- Resolução de desafios lógicos
- Exercícios de organização de passos

## Metodologia

A aula foi conduzida com foco em linguagem clara, exemplos práticos e atividades interativas, visando facilitar a compreensão das crianças.

## Aprendizados esperados

- Entender que programação é uma sequência de instruções
- Perceber que lógica organiza a solução de problemas
- Desenvolver curiosidade e interesse por tecnologia

## Observações

Esta foi a primeira aula do projeto e serviu como base inicial para o desenvolvimento das próximas etapas.
