# Programação e Desenvolvimento de Jogos para Crianças

Projeto social de educação tecnológica voltado para crianças, com foco em programação, lógica e criação de jogos.

## Objetivo

Introduzir crianças ao universo da tecnologia de forma acessível e prática, estimulando o raciocínio lógico, a criatividade e o interesse por programação.

## Conteúdo do projeto

- introdução à programação
- lógica e algoritmos
- sequência de instruções
- pensamento computacional
- atividades práticas e desafios simples
- desenvolvimento de ideias de jogos

## Estrutura das aulas

O projeto foi organizado em cinco encontros, com abordagem gradual e acessível:

1. Introdução à programação e lógica
2. Sequências e algoritmos
3. Programação visual e blocos
4. Ideação e criação de jogos
5. Revisão e atividades práticas

## Primeira aula

Na primeira aula, foram apresentados conceitos básicos de programação e lógica, com foco em:

- o que é programação
- algoritmos
- sequência de comandos
- raciocínio lógico
- atividades práticas

Foi um primeiro contato importante para mostrar que a programação pode ser acessível, interessante e criativa.
